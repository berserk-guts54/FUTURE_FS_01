# Personal Professional Portfolio

A personal portfolio website developed as part of the Future Interns Full Stack Web Development internship.

## About the Project

This website introduces me, highlights my technical skills and academic background, showcases my project work, and provides a way for visitors to contact me.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- EmailJS

## Features

- Personal introduction and About Me section
- Skills and education sections
- Project showcase with a GitHub repository link
- Responsive layout for mobile and desktop
- Contact form with email notifications
- Smooth navigation and hover effects

## Live Website

[View My Portfolio](https://berserk-guts54.github.io/FUTURE_FS_01/)

## Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Project Structure

- `index.html` — website structure
- `style.css` — styling and responsive layout
- `script.js` — JavaScript and contact form functionality
